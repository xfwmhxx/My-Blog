数据库定义 ​

数据库是“按照数据结构来组织、存储和管理数据的仓库”。是一个长期存储在计算机内的、有组织的、可共享的、统一管理的大量数据的集合。

应用场景 ​

在软件系统中无处不在，几乎所有的软件系统背后都有数据库，例如：

  • 淘宝
  • QQ
  • 游戏等

二、建表操作 ​

1. 使用SSMS图形界面建表 ​

  1. 在"对象资源管理器"中展开目标数据库
  2. 右键点击"表"文件夹，选择"新建表"
  3. 在表设计器中：
    • 添加列名、数据类型、是否允许NULL等属性
    • 设置主键（右键点击列名选择"设置主键"）

  4. 点击工具栏上的"保存"按钮，输入表名后确认

一、数据库的分离与附加 ​

1. 分离数据库 (Detach) ​

使用SSMS图形界面分离数据库： ​
  1. 打开SQL Server Management Studio (SSMS)
  2. 在"对象资源管理器"中展开"数据库"节点
  3. 右键点击要分离的数据库
  4. 选择"任务" > "分离"
  5. 在分离对话框中：
    • 勾选"删除连接"以断开所有活动连接
    • 勾选"更新统计信息"（可选）
    • 勾选"保留全文目录"（如果使用全文索引）
  6. 点击"确定"完成分离
使用T-SQL代码分离数据库： ​
sql
-- 分离数据库（需要先断开所有连接）
USE master;
GO

-- 设置数据库为单用户模式
ALTER DATABASE MyDatabase SET SINGLE_USER WITH ROLLBACK IMMEDIATE;
GO

-- 执行分离
EXEC sp_detach_db 'MyDatabase', 'true';  -- 'true'表示跳过更新统计信息
GO

​​分离与删除的区别​​：

  • ​​分离​​：仅从SQL Server实例中移除数据库引用，但保留完整的数据库文件(.mdf, .ldf)在磁盘上
  • ​​删除​​：不仅从SQL Server实例中移除数据库，还会删除磁盘上的数据库文件

2. 附加数据库 (Attach) ​

使用SSMS图形界面附加数据库： ​
  1. 在"对象资源管理器"中右键点击"数据库"节点
  2. 选择"附加"
  3. 在附加数据库对话框中点击"添加"
  4. 浏览并选择主数据文件(.mdf)
  5. 确认日志文件(.ldf)路径正确（如有变更需手动指定）
  6. 点击"确定"完成附加
使用T-SQL代码附加数据库： ​
sql
-- 附加数据库
USE master;
GO

CREATE DATABASE MyDatabase ON 
PRIMARY (FILENAME = 'C:\Data\MyDatabase.mdf'),
LOG ON (FILENAME = 'C:\Data\MyDatabase_log.ldf')
FOR ATTACH;
GO

-- 如果日志文件路径不同或需要指定多个文件
CREATE DATABASE MyDatabase ON 
PRIMARY (FILENAME = 'D:\SQLData\MyDatabase.mdf'),
(FILENAME = 'D:\SQLData\MyDatabase_Data1.ndf'),
LOG ON (FILENAME = 'E:\SQLLogs\MyDatabase_log.ldf')
FOR ATTACH;
GO

二、数据库的备份与还原 ​

1. 数据库备份 ​

使用SSMS图形界面备份： ​
  1. 右键点击要备份的数据库
  2. 选择"任务" > "备份"
  3. 在备份对话框中选择：
    • 备份类型：完整/差异/事务日志
    • 备份组件：数据库/文件和文件组
  4. 指定备份目标（磁盘或URL）
  5. 设置备份集名称和过期时间（可选）
  6. 点击"确定"执行备份
使用T-SQL代码备份： ​
sql
-- 完整备份
BACKUP DATABASE MyDatabase
TO DISK = 'C:\Backups\MyDatabase_Full.bak'
WITH INIT, NAME = 'MyDatabase-Full Backup', DESCRIPTION = 'Full backup of MyDatabase',
COMPRESSION, STATS = 10;
GO

-- 差异备份
BACKUP DATABASE MyDatabase
TO DISK = 'C:\Backups\MyDatabase_Diff.bak'
WITH DIFFERENTIAL, NAME = 'MyDatabase-Diff Backup', STATS = 10;
GO

-- 事务日志备份
BACKUP LOG MyDatabase
TO DISK = 'C:\Backups\MyDatabase_Log.trn'
WITH NAME = 'MyDatabase-Log Backup';
GO

2. 数据库还原 ​

使用SSMS图形界面还原： ​
  1. 右键点击"数据库"节点
  2. 选择"还原数据库"
  3. 在还原对话框中选择：
    • 源：设备（选择备份文件）或数据库
  4. 选择要还原的备份集
  5. 在"选项"页中：
    • 设置"覆盖现有数据库"（WITH REPLACE）
    • 指定数据文件和日志文件的新位置（如有需要）
  6. 点击"确定"执行还原
使用T-SQL代码还原： ​
sql
-- 完整还原（简单恢复模式）
USE master;
GO

RESTORE DATABASE MyDatabase
FROM DISK = 'C:\Backups\MyDatabase_Full.bak'
WITH REPLACE, RECOVERY,
MOVE 'MyDatabase_Data' TO 'D:\SQLData\MyDatabase.mdf',
MOVE 'MyDatabase_Log' TO 'E:\SQLLogs\MyDatabase.ldf',
STATS = 10;
GO

-- 完整+差异还原
RESTORE DATABASE MyDatabase
FROM DISK = 'C:\Backups\MyDatabase_Full.bak'
WITH NORECOVERY, REPLACE,
MOVE 'MyDatabase_Data' TO 'D:\SQLData\MyDatabase.mdf',
MOVE 'MyDatabase_Log' TO 'E:\SQLLogs\MyDatabase.ldf';

RESTORE DATABASE MyDatabase
FROM DISK = 'C:\Backups\MyDatabase_Diff.bak'
WITH RECOVERY;
GO

-- 时间点还原（完整恢复模式）
RESTORE DATABASE MyDatabase
FROM DISK = 'C:\Backups\MyDatabase_Full.bak'
WITH NORECOVERY, REPLACE;

RESTORE LOG MyDatabase
FROM DISK = 'C:\Backups\MyDatabase_Log.trn'
WITH RECOVERY, STOPAT = '2023-11-15 14:00:00';
GO

三、数据库脚本的保存 ​

1. 生成整个数据库的脚本 ​

使用SSMS生成脚本： ​
  1. 右键点击要生成脚本的数据库
  2. 选择"任务" > "生成脚本"
  3. 在向导中：
    • 选择要脚本化的对象（整个数据库或特定对象）
    • 设置脚本选项（包括架构和数据） (一般选择架构和数据)
    • 选择输出方式（文件、查询窗口或剪贴板）

高级脚本选项： ​
  • 包含IF NOT EXISTS语句
  • 生成DROP和CREATE语句
  • 包含权限脚本
  • 包含扩展属性
  • 生成数据插入脚本（使用"高级"选项中的"要编写脚本的数据类型"）

使用SSMS保存单个对象脚本： ​

字符串类型比较：char：定长，例如 char(10)，不论你存储的数据是否达到了10个字节，都要占去10个字节的空间 。 varchar：变长，例如varchar(10)，并不代表一定占用10个字节，而代表最多占用10个字节。最大长度8000，也可以使用varchar(max)表示2G以内的数据，但存储机制会和text一样，效率会降低。 text：长文本， 最大长度为2^31-1(2,147,483,647)个字符(几千几万字) 。

虽然text很强大，但是如果数据表里数据变多时，在进行检索时，text的效率会降低。

nchar,nvarchar,ntext：名字前面多了一个n， 它表示存储的是Unicode数据类型的字符，区别varchar(100)可以存储100个英文字母或者50个汉字，而nvarchar(100)可以存储100个英文字母，也可以存储100个汉字。

六、外键约束中的"拒绝"、"级联"和"设置空" ​

外键约束是关系数据库中维护数据完整性的重要机制，它定义了主表（被引用表）和从表（引用表）之间的操作规则。以下是三种主要外键约束行为的详细解释：

1. 拒绝（NO ACTION / RESTRICT） ​

含义 ​

当尝试删除或更新主表中的记录时，如果从表中存在引用该记录的外键值，数据库会拒绝执行该操作。

特点 ​

  • ​​默认行为​​：如果不指定ON DELETE或ON UPDATE规则，数据库默认使用NO ACTION
  • ​​严格数据完整性​​：确保不会出现"孤儿记录"（从表记录引用不存在的主表记录）
  • ​​需要手动处理​​：必须先删除或修改从表中的相关记录，才能操作主表记录

示例 ​

sql
-- 创建表时定义
CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
    -- 默认就是ON DELETE NO ACTION
);

-- 修改现有约束
ALTER TABLE orders
ADD CONSTRAINT fk_customer
FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
ON DELETE NO ACTION;

2. 级联（CASCADE） ​

含义 ​

三、drop、truncate、delete区别 ​

drop table:删除表对象，表数据、表结构、表对象都进行了删除。 delete和truncate table：删除表数据，表对象及表结构依然存在。 delete与truncate table的区别如下： delete： （1）可以删除表所有数据，也可以根据条件删除数据。 （2）如果有自动编号，删除后继续编号，例如delete删除表所有数据后，之前数据的自动编号是1，2，3，那么之后新增数据的编号从4开始。 truncate table： （1）只能清空整个表数据，不能根据条件删除数据。 （2）如果有自动编号，清空表数据后重新编号，例如truncate table清空表所有数据后，之前数据的自动编号是1，2，3，那么之后新增数据的编号仍然从1开始。

create function GetAgeByBirth(@birth smalldatetime)
returns int
as
begin
    declare @age int
    set @age = year(getdate()) - year(@birth)
    if month(getdate()) < month(@birth)
        set @age = @age - 1
    if month(getdate()) = month(@birth) and day(getdate()) < day(@birth)
        set @age = @age -1
    return @age
end

（5）具有同时输入输出参数的存储过程 密码升级，传入用户名和密码，如果用户名密码正确，并且密码长度<8，自动升级成8位密码

sql
--有输入输出参数（密码作为输入参数也作为输出参数）
--密码升级，传入用户名和密码，如果用户名密码正确，并且密码长度<8，自动升级成8位密码
select FLOOR(RAND()*10) --0-9之间随机数
create proc procPwdUpgrade
@cardno nvarchar(20),
@pwd nvarchar(20) output
as
    if not exists(select * from BankCard where CardNo=@cardno and CardPwd=@pwd)
        set @pwd = ''
    else
    begin
        if len(@pwd) < 8
        begin
            declare @len int = 8- len(@pwd)
            declare @i int = 1
            while @i <= @len
            begin
                set @pwd = @pwd + cast(FLOOR(RAND()*10) as varchar(1))
                set @i = @i+1
            end
            update BankCard set CardPwd = @pwd where CardNo=@cardno
        end
    end
go
declare @pwd nvarchar(20) = '123456'
exec procPwdUpgrade '6225547854125656',@pwd output
select @pwd
