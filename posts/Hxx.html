主要改进点：

​1. ​支持多种PPT文件格式​​：添加了supportedExtensions数组，包含常见的PPT文件格式：.pptx, .ppt, .ppsx, .pps, .odp, .pdf, .jpg, .jpeg, .png, .gif, .key, .svg。

2025-04-26 01:58:44 修改 ​​SSR（服务器端渲染）与客户端API不兼容​​ 问题

错误原因​​:

  1. ​​根本问题​​：代码中直接使用了浏览器专属对象 window，但在构建时VitePress会在Node.js环境下执行SSR（服务器端渲染），此时window不存在。
  2. 常见触发场景​​：
  • 直接使用了localStorage/sessionStorage
  • 调用了document相关API
  • 使用了仅浏览器支持的API（如fetch的某些polyfill）

解决方案:

  1. 最安全的SSR兼容写法
js
// 修改缓存代码，添加环境判断
async loadPPTFiles() {
  // 添加SSR保护
  if (typeof window === 'undefined') return
  
  const cacheKey = `ppt-cache`
  const cached = window.sessionStorage?.getItem(cacheKey)
  
  if (cached) {
    this.processFiles(JSON.parse(cached))
    return
  }

  const files = await this.fetchRepoContents(this.config.folder)
  window.sessionStorage?.setItem(cacheKey, JSON.stringify(files))
  this.processFiles(files)
}
