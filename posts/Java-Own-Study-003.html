Java语言基础

1.数据类型 ​

1.在程序设计中，数据是程序的必要组成部分，也是程序处理的对象。

2.Java中的数据类型分为两大类，一类是基本数据类型，简称基本类型；另一类是引用和数据类型，简称引用类型。

基本数据类型在内存中存放的是数据值本身。引用数据类型在内存中存放的是指向该数据的地址，而不是数据值本身。

引用数据类型在内存中存放的是指向该数据的地址，而不是数据值本身，它往往由多个基本数据类型组成。

基本数据类型有整数型、浮点型、布尔型和字符型。 引用数据类型包括数组、类和接口等。

3.Java定义了4类共8种基本类型，其中有4种整数型、2种浮点型、1种布尔型和1种字符型。

整数型：byte、short、int、long 浮点型：float、double 布尔型：boolean 字符型：char

3.常量 ​

3.1 定义 ​

常量是指在程序执行过程中，其值不能改变的量。在 Java 中，常量的值在声明时被初始化后不可被修改。

3.2 关键字 ​

Java 使用 final 关键字来声明常量。使用 final 修饰的变量在初始化后，不能再被赋值。

3.3 声明常量的语法 ​

常量的声明通常遵循以下语法：

final 数据类型 常量名 = 常量值;
1

3.4 命名约定 ​

  • 常量名通常使用全大写字母，单词之间用下划线分隔。例如：MAX_VALUE、PI。

3.5 常量的类型 ​

  • 基本数据类型常量: 如 int、float、double 等。

    final int MAX_AGE = 100;
final double PI = 3.14159;
    1
    2

  • 引用类型常量: 如字符串常量。

    final String GREETING = "Hello, World!";
    1

3.6 使用常量的优点 ​

  • 可读性: 使用常量可以使代码更具可读性，表达意图更清晰。
  • 维护性: 修改常量的值只需在一个地方进行，减少了出错的可能性。
  • 避免魔法数字: 使用常量可以避免在代码中出现难以理解的数字或字符串。

3.7 示例代码 ​

以下是使用常量的示例：

public class Circle {
    public static final double PI = 3.14159; // 圆周率常量

    public static double calculateArea(double radius) {
        return PI * radius * radius; // 使用常量
    }
}

4.变量 ​

4.1 定义 ​

变量是程序中用于存储数据的命名内存位置。每个变量都有一个特定的数据类型，决定了可以存储何种类型的数据。

4.2 变量的类型 ​

Java 中的变量主要分为两种类型：

  • 基本数据类型变量: 存储基本数据类型的值，包括：
    • int、float、double、char、boolean 等。
  • 引用类型变量: 存储对象的引用，包括：
    • 自定义类、数组、接口等。

4.3 变量的声明和初始化 ​

变量的声明和初始化通常遵循以下语法：

数据类型 变量名;          // 声明变量
变量名 = 值;             // 初始化变量
1
2

可以在一行中同时声明和初始化变量：

数据类型 变量名 = 值;
1

4.4 变量的命名规则 ​

  • 变量名可以包含字母、数字、下划线和美元符号，但不能以数字开头。
  • 变量名不能是 Java 的关键字。
  • 变量名应具有描述性，以提高代码可读性。

4.5 变量的作用域 ​

变量的作用域决定了它在程序中的可见性和生命周期：

  • 局部变量: 在方法或代码块内部声明的变量，只能在该方法或代码块内部访问。

  • 实例变量: 在类中声明的变量，每个对象都有自己的副本。

  • 类变量（静态变量）: 使用 static 关键字声明的变量，属于类而不是某个对象，所有对象共享同一副本。

4.6 示例代码 ​

以下是一个简单的示例，演示了变量的声明、初始化和使用：

public class VariableExample {
    // 类变量
    static int classVariable = 10;

    // 实例变量
    int instanceVariable;

    public VariableExample(int value) {
        // 初始化实例变量
        this.instanceVariable = value;
    }

    public void displayVariables() {
        // 局部变量
        int localVariable = 5;
        System.out.println("Class Variable: " + classVariable);
        System.out.println("Instance Variable: " + instanceVariable);
        System.out.println("Local Variable: " + localVariable);
    }

    public static void main(String[] args) {
        VariableExample example = new VariableExample(20);
        example.displayVariables();
    }
}

5.数据类型之间的转换 ​

5.1 数据类型分类 ​

Java 中的数据类型主要分为两种：

  • 基本数据类型: 包括 byte、short、int、long、float、double、char 和 boolean。
  • 引用数据类型: 包括对象、数组和字符串。

5.2 转换类型 ​

在 Java 中，数据类型之间的转换主要分为两种类型：

5.2.1 自动类型转换（隐式转换） ​

自动类型转换发生在一种数据类型的值被赋给另一种更大范围的数据类型时，Java 会自动进行转换。例如：

int intValue = 100;
long longValue = intValue; // int 转换为 long
float floatValue = longValue; // long 转换为 float
1
2
3

注意事项:

  • 自动转换不会导致数据丢失。
  • 只能在兼容类型之间进行自动转换。

转换的优先级： byte → short → char → int → long → float → doubleboolean因为只能存放true和false，与整数型及字符型不兼容，因此不可能做类型转换。

在一个表达式中若有整数型为short或byte的数据参加计算，为了避免溢出，Java会将表达式中的short和byte类型的数据自动转换为int类型。

值得注意的是，类型的转换只限该语句本身，并不会影响原先变量的类型定义，而且通过自动类型转换可以保证数据的精确度，它不会因为类型转换而损失数据的内容。

5.2.2 强制类型转换（显式转换） ​

强制类型转换发生在一种数据类型的值被赋给另一种更小范围的数据类型时，必须使用强制转换操作符。格式如下：

java
数据类型 变量名 = (目标数据类型) 值;
1

例如：

java
double doubleValue = 9.78;
int intValue = (int) doubleValue; // double 转换为 int，结果为 9
1
2

注意事项:

  • 强制转换可能导致数据丢失或精度下降。
  • 只能在兼容类型之间进行强制转换。

5.3. 特殊转换 ​

  • 字符与整数之间的转换:

    • 可以将字符类型转换为整数类型，表示其 Unicode 值。

      java
      char charValue = 'A';
int intValue = charValue; // A 的 Unicode 值为 65
      1
      2

    • 反之，整数也可以转换为字符：

      java
      int intValue = 65;
char charValue = (char) intValue; // 转换为字符 'A'
      1
      2

  • 字符串与基本数据类型之间的转换:

    • 字符串可以通过包装类的方法转换为基本数据类型：

      java
      String strValue = "123";
int intValue = Integer.parseInt(strValue); // 字符串转换为 int
      1
      2

    • 反之，可以使用 String.valueOf() 方法将基本数据类型转换为字符串：

      java
      int intValue = 123;
String strValue = String.valueOf(intValue); // int 转换为字符串
      1
      2

字符串转换为数值型数据的方法

转换方法功能说明

Long.parseLong(String s)将字符串转换为 long 类型
Float.parseFloat(String s)将字符串转换为 float 类型
Double.parseDouble(String s)将字符串转换为 double 类型
Short.parseShort(String s)将字符串转换为 short 类型

5.4 示例代码 ​

以下是一个示例，展示了不同类型的转换：

java
public class TypeConversionExample {
    public static void main(String[] args) {
        // 自动转换
        int intValue = 100;
        long longValue = intValue; // 自动转换
        System.out.println("Long Value: " + longValue);

        // 强制转换
        double doubleValue = 9.78;
        int convertedValue = (int) doubleValue; // 强制转换
        System.out.println("Converted Int Value: " + convertedValue);

        // 字符与整数转换
        char charValue = 'A';
        int unicodeValue = charValue; // char 转 int
        System.out.println("Unicode Value of 'A': " + unicodeValue);

        // 字符串与基本数据类型转换
        String strValue = "123";
        int parsedValue = Integer.parseInt(strValue); // 字符串转 int
        System.out.println("Parsed Int Value: " + parsedValue);

        String fromInt = String.valueOf(parsedValue); // int 转字符串
        System.out.println("String from Int: " + fromInt);
    }
}

6.局部变量的类型推断 ​

6.1 定义 ​

局部变量类型推断是 Java 10 引入的一项特性，允许编译器根据变量初始化时的值自动推断变量的类型，而不需要显式声明类型。

6.2 使用 var 关键字 ​

在局部变量声明时，使用 var 关键字来代替具体的数据类型。编译器根据赋值的右侧表达式来推断变量的类型。

6.3 示例 ​

以下是局部变量类型推断的使用示例：

java
public class VarExample {
    public static void main(String[] args) {
        var number = 10;          // 推断为 int
        var name = "Java";        // 推断为 String
        var pi = 3.14;           // 推断为 double
        var list = new ArrayList<String>(); // 推断为 ArrayList<String>

        System.out.println("Number: " + number);
        System.out.println("Name: " + name);
        System.out.println("Pi: " + pi);
        System.out.println("List: " + list);
    }
}

6.4 注意事项 ​

  • 局部变量: var 只能用于局部变量，不能用于成员变量、方法参数或返回类型。

  • 初始化: 使用 var 声明的变量必须在同一行进行初始化，编译器才能推断其类型。

  • 类型推断: 一旦推断出类型，变量的类型在其作用域内是固定的，不能再改变。

  • 可读性: 虽然 var 提高了代码的简洁性，但过度使用可能会降低代码的可读性，特别是在复杂表达式中。

6.5 示例代码 ​

以下是使用 var 关键字的示例代码，展示了类型推断的优势和限制：

import java.util.ArrayList;

public class VarExample {
    public static void main(String[] args) {

        var name = "Hello"; // String
        var list = new ArrayList<String>(); // ArrayList<String>

        // 不能使用 var 进行未初始化的声明
        // var uninitialized; // 错误: 不能推断类型

        // 输出变量
        System.out.println("Number: " + number);
        System.out.println("Name: " + name);
        System.out.println("List: " + list);
    }
}

7.从键盘输入数据 ​

7.1 使用 Scanner 类 ​

在 Java 中，可以使用 Scanner 类从键盘输入数据。Scanner 类位于 java.util 包中，提供了多种方法来读取不同类型的数据。

7.2 引入 Scanner 类 ​

在使用 Scanner 之前，首先需要导入它：

java
import java.util.Scanner;
1

7.3 创建 Scanner 对象 ​

通过 new 关键字创建 Scanner 对象，并将 System.in 作为参数传入，以便从标准输入流（键盘）读取数据：

Scanner scanner = new Scanner(System.in);
1

7.4 读取输入数据 ​

Scanner 类提供了多种方法来读取不同类型的数据：

  • nextLine(): 读取一行字符串
  • next(): 读取一个单词（空格分隔）
  • nextInt(): 读取一个整数
  • nextDouble(): 读取一个双精度浮点数
  • nextBoolean(): 读取一个布尔值

7.5 示例代码 ​

以下是一个示例，演示如何从键盘输入数据：

java
import java.util.Scanner;

public class InputExample {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);

        // 读取字符串
        System.out.print("请输入你的名字: ");
        String name = scanner.nextLine();

        // 读取整数
        System.out.print("请输入你的年龄: ");
        int age = scanner.nextInt();

        // 读取浮点数
        System.out.print("请输入你的身高 (米): ");
        double height = scanner.nextDouble();

        // 输出结果
        System.out.println("名字: " + name);
        System.out.println("年龄: " + age);
        System.out.println("身高: " + height + " 米");

        // 关闭 scanner
        scanner.close();
    }
}

8.运算符与表达式(此部分建议看书本P35) ​

8.1 运算符 ​

运算符是用于执行操作的符号。Java 提供了多种类型的运算符，主要包括：

8.1.1 算术运算符 ​

用于执行基本的数学运算：

  • + : 加法
  • - : 减法
  • * : 乘法
  • / : 除法
  • % : 取模（求余数）

8.1.2 关系运算符 ​

用于比较两个值，返回布尔类型（true 或 false）：

  • == : 等于
  • != : 不等于
  • > : 大于
  • < : 小于
  • >= : 大于或等于
  • <= : 小于或等于

8.1.3 逻辑运算符 ​

用于连接布尔表达式：

  • &&（逻辑与）:

    • 当且仅当两个操作数都为 true 时，结果为 true。
    • 示例：true && false 的结果为 false。

  • ||（逻辑或）:

    • 只要有一个操作数为 true，结果为 true。
    • 示例：true || false 的结果为 true。

  • !（逻辑非）:

    • 反转操作数的布尔值，true 变为 false，反之亦然。
    • 示例：!true 的结果为 false。

  • &（逻辑与）:

    • 类似于 &&，但无短路行为，两个操作数都被计算。
    • 示例：true & false 的结果为 false。

  • |（逻辑或）:

    • 类似于 ||，但无短路行为，两个操作数都被计算。
    • 示例：true | false 的结果为 true。

  • ^（逻辑异或）:

    • 当且仅当一个操作数为 true，另一个为 false 时，结果为 true。
    • 示例：true ^ false 的结果为 true。

8.1.4 位运算符 ​

用于对二进制位进行操作：

  • &（按位与）:

    • 对应位都为 1 时，结果位为 1。
    • 示例：5 & 3（0101 & 0011）结果为 1（0001）。

  • |（按位或）:

    • 只要有一个对应位为 1，结果位为 1。
    • 示例：5 | 3（0101 | 0011）结果为 7（0111）。

  • ^（按位异或）:

    • 对应位不同则结果位为 1。
    • 示例：5 ^ 3（0101 ^ 0011）结果为 6（0110）。

  • ~（按位取反）:

    • 反转每一位，0 变为 1，1 变为 0。
    • 示例：~5（0101）结果为 -6（1111...1010）。

  • <<（左移）:

    • 将操作数的位向左移动指定的位数，右侧补 0。
    • 示例：5 << 1（0101）结果为 10（1010）。

  • >>（右移）:

    • 将操作数的位向右移动指定的位数，符号位补充。
    • 示例：5 >> 1（0101）结果为 2（0010）。

  • >>>（无符号右移）:

    • 将操作数的位向右移动指定的位数，左侧补 0。
    • 示例：-5 >>> 1 结果为 2147483645。

  • = : 赋值
  • += : 加并赋值
  • -= : 减并赋值
  • *= : 乘并赋值
  • /= : 除并赋值
  • %= : 取模并赋值

8.2 表达式 ​

表达式是由运算符和操作数组成的一段代码，计算后返回一个值。表达式可以是简单的，也可以是复杂的。

8.2.1 示例表达式 ​

  • 算术表达式：

    int result = (5 + 3) * 2; // 结果为 16
    1

  • 关系表达式：

    boolean isEqual = (5 == 5); // 结果为 true
    1

  • 逻辑表达式：

    boolean result = (5 > 3) && (3 < 10); // 结果为 true
    1

  • 条件表达式：

    int max = (a > b) ? a : b; // 返回 a 和 b 中的较大值
    1

8.3 示例代码 ​

以下是一个示例，展示运算符与表达式的使用：

public class OperatorExample {
    public static void main(String[] args) {
        int a = 10, b = 20;

        // 算术运算
        int sum = a + b;
        System.out.println("Sum: " + sum);

        // 关系运算
        boolean isGreater = a > b;
        System.out.println("Is A greater than B? " + isGreater);

        // 逻辑运算
        boolean result = (a < b) && (b > 15);
        System.out.println("Result of logical operation: " + result);

        // 条件运算
        int max = (a > b) ? a : b;
        System.out.println("Max value: " + max);
    }
}

1()括号从左到右
