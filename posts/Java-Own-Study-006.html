类与对象

1.定义类 ​

1.1 类修饰符的含义表 ​

修饰符含义
public类可以被任何其他类访问。
protected类只能在同一包中或其子类中访问。
private类只能在其定义的文件中访问。
无修饰符类只能在同一包中访问（也称为包私有或默认访问）。
abstract类不能实例化，必须由子类实现其抽象方法。
final类不能被继承，不能作为父类。
static类的成员（方法或字段）属于类本身，而不是类的实例。

1.2 成员变量修饰符的含义表 ​

修饰符含义
public公共访问控制符。成员变量可以被任何其他类访问。
protected保护访问控制符。成员变量只能在同一包中 或 其子类 或 自己的类中访问。
private私有访问控制符。成员变量只能在其定义的类（自己的类）中访问。
无修饰符成员变量只能在同一包中访问（也称为包私有或默认访问）。
final最终修饰符。成员变量的值一旦初始化后不能被修改。
static静态修饰符。成员变量属于类本身，而不是类的实例，所有实例共享同一个值。
transient过渡修饰符。成员变量在序列化时不会被序列化。
volatile易失修饰符。成员变量的值可能会被多个线程修改，确保每次读取都是最新值。

处理访问控制修饰符有多个之外，其他的修饰符都只有一个。

一个成员变量可以被两个以上的修饰符同时修饰，但有些修饰符是不能同时定义在一起的。

1.3 成员方法 ​

声明方法的语法格式：

[修饰符] 返回类型 方法名([参数列表]) {
    // 方法体
    [return 返回值;]
}

成员方法修饰符的含义：

修饰符含义
public公共访问控制符。方法可以被任何其他类访问。
protected保护访问控制符。方法只能在同一包中或其子类中访问。
private私有访问控制符。方法只能在其定义的类中访问。
无修饰符方法只能在同一包中访问（也称为包私有或默认访问）。
static静态修饰符。方法属于类本身，而不是类的实例，可以通过类名直接调用。
final最终修饰符。方法不能被重写，子类无法修改该方法的实现。
abstract抽象修饰符。方法没有具体实现，必须由子类提供实现。
synchronized同步修饰符。方法在多线程环境中执行时，确保同一时刻只有一个线程可以执行该方法。
native本地修饰符。方法的实现由本地代码（如 C/C++）提供，通常用于与系统或硬件交互。

2.对象的创建与使用 ​

在 Java 中，对象是类的实例，创建和使用对象是面向对象编程的核心。以下是关于 Java 对象创建与使用的详细说明：

2.1 类与对象的关系 ​

  • 类：是对象的蓝图或模板，定义了对象的属性（字段）和行为（方法）。
  • 对象：是类的实例，具有类中定义的属性和方法。

2.2 创建对象 ​

在 Java 中，创建对象的基本语法使用 new 关键字：

ClassName objectName = new ClassName();
1

示例 ​

假设有一个 Dog 类：

public class Dog {
    // 属性
    private String name;
    private int age;

    // 构造方法
    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    // 方法
    public void bark() {
        System.out.println(name + " says: Woof!");
    }
}

2.3 使用对象 ​

创建对象后，可以使用该对象调用类中的方法和访问属性。

调用方法 ​

使用 . 运算符调用对象的方法：

myDog.bark(); // 输出: Buddy says: Woof!
1

访问属性 ​

如果属性是私有的，通常需要通过公共方法（getter 和 setter）进行访问。例如：

public String getName() {
    return name;
}

public void setName(String name) {
    this.name = name;
}

2.4 对象的生命周期 ​

  • 创建：使用 new 关键字创建对象。
  • 使用：调用对象的方法和访问属性。
  • 销毁：当对象不再被引用时，Java 的垃圾回收机制会自动回收其占用的内存。

2.5 示例代码 ​

以下是一个完整的示例，展示了对象的创建与使用：

public class Dog {
    private String name;
    private int age;

    public Dog(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void bark() {
        System.out.println(name + " says: Woof!");
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }
}

public class Main {
    public static void main(String[] args) {
        // 创建对象
        Dog myDog = new Dog("Buddy", 3);

        // 使用对象
        myDog.bark(); // 输出: Buddy says: Woof!
        System.out.println("Dog's name: " + myDog.getName()); // 输出: Dog's name: Buddy

        // 修改对象属性
        myDog.setName("Max");
        System.out.println("Dog's new name: " + myDog.getName()); // 输出: Dog's new name: Max
    }
}

3.匿名对象 ​

在 Java 中，匿名对象是指没有给对象指定名称的对象。它通常用于临时使用，不需要在后续代码中引用该对象。使用匿名对象的主要目的是简化代码，特别是在只需要一次性使用对象的情况下。

3.1 匿名对象的创建 ​

创建匿名对象时，使用 new 关键字直接调用构造方法，而不为其分配变量名。例如：

new Dog("Buddy", 3).bark();
1

在这个例子中，创建了一个 Dog 类型的匿名对象，调用了其 bark() 方法，但没有保存对该对象的引用。

3.2 匿名对象的使用场景 ​

  • 临时使用：当你只需要使用对象一次时，可以直接使用匿名对象。
  • 简化代码：减少不必要的变量声明，使代码更简洁。
  • 事件处理：在 GUI 编程中，匿名对象常用于事件监听器的实现。

3.3 示例代码 ​

以下是一个使用匿名对象的示例：

public class Dog {
    private String name;

    public Dog(String name) {
        this.name = name;
    }

    public void bark() {
        System.out.println(name + " says: Woof!");
    }
}

public class Main {
    public static void main(String[] args) {
        // 创建并使用匿名对象
        new Dog("Buddy").bark(); // 输出: Buddy says: Woof!
        
        // 可以多次创建匿名对象
        new Dog("Max").bark();   // 输出: Max says: Woof!
    }
}

3.4 匿名对象的限制 ​

  • 无法重用：由于没有引用，无法在后续代码中再次使用该对象。
  • 不能访问实例变量：如果需要访问对象的实例变量，必须先给对象命名。
